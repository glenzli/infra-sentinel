# Infra Sentinel 2.1.1

本次修复同一客户端切换模型后速度记录互相覆盖，以及今日视图列出历史模型速度的问题。

## 更新内容

- Codex、OpenCode、DSH、Antigravity 按精确模型名分别保留最近有效的速度记录。切换模型后，其他模型的记录继续保留。
- 用量总览和模型分析的速度样本跟随右上角时间范围筛选；今日只显示今日样本，7 天、30 天和全部同理。
- 样本旁直接显示模型名，悬停或键盘聚焦可查看记录时间、延迟、耗时和计时口径。
- Codex 从可读取的旧日志分批补齐各模型计时，进程重启后可继续，无需手动重建账本，也不会重复累计 Token。

轮次平均、请求平均和客户端流速继续分别标注；包含等待或工具执行的平均值不代表纯模型生成速度。

## Changes

- Retain each exact model's latest usable speed independently within Codex, OpenCode, DSH, and Antigravity.
- Filter inline speed samples to the selected calendar range in usage overview and model analysis, rather than listing every historical model in today's view.
- Show model names beside samples, with recording time and timing details available on hover or keyboard focus.
- Backfill per-model Codex timing from readable older logs in bounded, resumable batches without rebuilding or replaying Token accounting.

Turn averages, request averages, and client stream rates retain their separate timing scopes. Averages that include waiting or tools are not pure model generation speeds.
