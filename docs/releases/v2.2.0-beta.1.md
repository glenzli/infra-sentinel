# Infra Sentinel 2.2.0-beta.1

Windows x64 原生日常预览版。本次仅提供 Windows 安装包；macOS 稳定版继续使用 [2.1.2](https://github.com/glenzli/infra-sentinel/releases/tag/v2.1.2)。

安装前请从托盘退出正在运行的 Infra Sentinel。

## 更新内容

- 原生桌面、托盘、重复启动激活已有窗口、后台 Agent 监督和设置保存后的自动重启。
- 原生 CPU、内存和磁盘容量观测，AI 客户端用量、公开上游状态及已有 OpenSSH 远端接入。
- Codex 遵循 `CODEX_HOME`，聚合账本在重启后继续累积；通过只读真实日志核对账本、增量及今日、7 天、30 天和全部历史的界面汇总。
- Infra Protocol 原生 Named Pipe 消费端，支持 PCP、Infer Runtime、Dev Mesh Observer 的既有应用协议，包含注册文件 ACL、管道服务端 SID、请求时限和取消收尾。
- 当前用户安装，内含 Agent、默认配置和 WebView2 引导程序；无需另装 Python、Node.js 或 Rust。缺少 WebView2 时，引导程序需要联网。

## 已知限制

- 安装包未签名，适合日常试用与反馈。当前仅提供 Windows x64。
- 本机 Mihomo Controller 和 Windows 系统通知尚未支持；未支持的本机流量观测保持停用，不产生故障或零值指标。
- 三个设施协议已通过真实 Windows 管道及打包 Agent 的合同夹具验收；实际产品仍需发布兼容的 Windows offer 后完成实机联调。不会自动接入 WSL 内的 Unix Socket。
- 睡眠恢复、长时间运行及更多真实客户端和远端组合仍需持续验证。
- 本次没有新的 macOS 二进制包，Linux 桌面发布后置。

Token 数据来自本机可见记录，不代表账户剩余额度或账单。采集不保留提示词、响应正文或凭据。

## Changes

- Add a native Windows desktop/tray, single-instance activation, supervised console-free Agent and settings restart.
- Support native CPU, memory and disk-capacity observation, AI-client usage, public upstream status and existing OpenSSH connections.
- Honor `CODEX_HOME` and qualify persistent Codex accounting, restart increments and production UI aggregates with read-only real rollout metadata.
- Add native Infra Protocol byte-stream Named Pipe consumption for PCP, Infer Runtime and Dev Mesh Observer, with private Discovery ACLs, connected-server SID checks and bounded I/O cancellation.
- Bundle a current-user NSIS installer, the Agent, default configuration and WebView2 bootstrapper. No Python, Node.js or Rust installation is required; WebView2 bootstrap may need internet access.

## Preview limits

Unsigned Windows x64 installer; quit any running Infra Sentinel from its tray menu before installation. Local Mihomo Controller and Windows notifications remain pending. Facility contract fixtures pass, while real-product Windows interoperability requires compatible provider offers. WSL Unix sockets are not automatically bridged. Extended sleep/resume and long-running use remain under validation. No new macOS binary is included; macOS stable remains 2.1.2.

Token counters describe visible local records, not account quota or billing. Prompts, responses and credentials are not retained.
