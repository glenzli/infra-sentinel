# Infra Sentinel 2.3.0

本版发布 macOS 13+ Apple Silicon 稳定安装包，统一源码版本为 2.3.0。
已完成构建、整轮 UI 布局和真实遥测验收。
各平台的发布和稳定性标记分别维护；现有 Windows 下载仍为 2.2.0-beta.1，
新版 Windows 和 Linux 安装包需各自在目标平台完成验收后发布。

## 更新内容

- 可选的 Codex 本机遥测：显式配置一次，使用带认证的回环 OTLP 日志接收器，
  仅保存有界的模型计数与计时，不保存提示词、响应、账户或原始遥测正文。
- 按精确模型保留请求样本。正常视图只显示流速和首 Token 延迟；Codex
  估算流速扣除同一次请求的首输出等待，缺失、非法和过短计时不生成估算。
- 性能提示只保留来源、模型、样本时间，完整说明集中在「口径与估算」。
- 补充接收状态、配对及拒绝诊断，并说明 macOS 系统代理的回环例外边界。
- 内置更新后的模型参考价格与 GPT-6.1 Terra 计价支持。
- 隔离 Codex / AGY CLI 可由外层运行器提交最小数字用量回执，按稳定尝试编号
  去重并持久保存，纳入按模型、自然日和小时的统计；不保存提示词或回答，
  不依赖遥测，不推算速度。
- 回执接入共用的日期价目和已知 effort 后缀规则，例如
  `gemini-3.8-flash-high` 按 `gemini-3.8-flash` 的适用日期参考价估算。
  保留原始模型名，推理不重复计数，缺少必要缓存细分时保持未估价。
- 全应用共用紧凑页头，将统计周期、状态与导航合在一起，压缩卡片、
  Tab 与空状态的占用；中英文窄窗口按内容换行。
- 概览的异常与恢复入口并入健康卡；AI 时段总量并入图表标题；
  网络账单和观测链路合为一张卡，保留同一时间范围与不可相加的说明。
- 网络、AI、本机系统、设施和上游状态使用可展开的告警证据，
  严重告警默认展开，支持键盘操作并在刷新后保留选择。
- 图表边缘提示向内对齐，避免隐藏提示框撑出横向滚动。

## 启用方式与范围

遥测默认不启用。从源码运行
`PYTHONPATH=src python3 -m infra_sentinel.cli.codex_telemetry enable`，
或调用打包 Agent 的 `infra-agent --codex-telemetry enable`，即可自动备份
并写入受管理的 Codex 配置；已有第三方遥测配置会保留并报告冲突。

启用后重启 Sentinel 与已有 Codex 进程，并核对新的样本时间和接收计数。
当前入口为命令行；macOS 回环代理例外单独配置，设置页一键启用尚未提供。
详见 [Codex 本机请求遥测](../codex-telemetry.md)。遥测不改变既有用量账本。

隔离 CLI 的统计由外层运行器在调用结束后提交
[用量回执](../cli-usage-receipts.md)，不会自动修改第三方运行器或扫描任意临时目录。
已有常规 Codex、AGY 或 Infer Runtime 记录的调用不应再次提交。
API 参考价值用于比较用量，不代表提供方实际账单。

## Changes

- Add explicit, reversible local Codex telemetry setup and an authenticated,
  resource-bounded loopback receiver. Only model counts and timing are retained.
- Display per-model stream rates and first-token delay. Codex estimates subtract
  waiting from the same request and omit missing, invalid or very short timing.
- Keep sample tooltips to source, model and timestamp; move full explanations
  to Methods & estimates. Add matching/rejection diagnostics and proxy guidance.
- Bundle updated model reference prices and GPT-6.1 Terra accounting support.
- Record isolated Codex/AGY CLI usage through minimal numeric receipts submitted
  by the outer runner. Stable attempt identities prevent duplicate accounting
  across delivery retries and restarts; daily/model/hour totals retain no content.
- Price receipts with the shared dated catalog and known effort suffixes while
  preserving raw model IDs. Include reasoning once and leave usage without the
  required cache breakdown unpriced.
- Share compact session/status/navigation headers across resource pages,
  reducing card, tab and empty-state whitespace with bilingual narrow-window wrapping.
- Merge overview diagnostic history into the health card, AI range totals into
  chart headings, and network billing into the same-window observation path.
- Keep attention titles visible with keyboard-accessible evidence disclosures.
  Critical evidence starts open; live refreshes retain the user's choices.
- Keep time-bucket hints inside chart edges to prevent horizontal overflow.

## Setup and platform scope

Run the explicit enable command once to back up and configure Codex, then restart
Sentinel and existing Codex processes. Setup preserves conflicting exporters.
The current entry point is CLI-only; macOS loopback proxy exceptions are a
separate setup step. Verify a new sample and receiving counters after restart.

Isolated CLI accounting requires an explicit outer-runner integration with the
[receipt entry point](../cli-usage-receipts.md). Sentinel does not patch third-party
runners or discover arbitrary temporary state. Do not resubmit calls already
counted by regular Codex, AGY or Infer Runtime sources. Price values are public
text API references, not provider bills.

The macOS 13+ Apple Silicon stable package uses shared source version 2.3.0.
The packaged application, compact UI and real Sol/Astra desktop telemetry have
been validated. Published Windows downloads remain 2.2.0-beta.1;
new Windows/Linux artifacts require their own target-platform acceptance.
