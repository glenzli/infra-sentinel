# Infra Sentinel 2.3.0

本轮使用统一源码版本 2.3.0，并在 macOS 上完成构建与真实遥测验收。
各平台的发布和稳定性标记分别维护；现有 Windows 下载仍为 2.2.0-beta.1，
新版 Windows 和 Linux 安装包需各自在目标平台完成验收后发布。

## 更新内容

- 可选的 Codex 本机遥测：显式配置一次，使用带认证的回环 OTLP 日志接收器，
  仅保存有界的模型计数与计时，不保存提示词、响应、账户或原始遥测正文。
- 按精确模型保留请求样本。正常视图只显示流速和首 Token 延迟；Codex
  估算流速扣除同一次请求的首输出等待，缺失、非法和过短计时不生成估算。
- 性能提示只保留来源、模型、样本时间，完整说明集中在「口径与估算」。
- 补充接收状态、配对及拒绝诊断，并说明 macOS 系统代理的回环例外边界。
- 内置更新后的模型参考价格与 GPT-6.1 Terra 计价支持。

## 启用方式与范围

遥测默认不启用。从源码运行
`PYTHONPATH=src python3 -m infra_sentinel.cli.codex_telemetry enable`，
或调用打包 Agent 的 `infra-agent --codex-telemetry enable`，即可自动备份
并写入受管理的 Codex 配置；已有第三方遥测配置会保留并报告冲突。

启用后重启 Sentinel 与已有 Codex 进程，并核对新的样本时间和接收计数。
当前入口为命令行；macOS 回环代理例外单独配置，设置页一键启用尚未提供。
详见 [Codex 本机请求遥测](../codex-telemetry.md)。遥测不改变既有用量账本。

## Changes

- Add explicit, reversible local Codex telemetry setup and an authenticated,
  resource-bounded loopback receiver. Only model counts and timing are retained.
- Display per-model stream rates and first-token delay. Codex estimates subtract
  waiting from the same request and omit missing, invalid or very short timing.
- Keep sample tooltips to source, model and timestamp; move full explanations
  to Methods & estimates. Add matching/rejection diagnostics and proxy guidance.
- Bundle updated model reference prices and GPT-6.1 Terra accounting support.

## Setup and platform scope

Run the explicit enable command once to back up and configure Codex, then restart
Sentinel and existing Codex processes. Setup preserves conflicting exporters.
The current entry point is CLI-only; macOS loopback proxy exceptions are a
separate setup step. Verify a new sample and receiving counters after restart.

The shared source version is 2.3.0. macOS build and real Sol/Astra desktop
telemetry have been validated. Published Windows downloads remain 2.2.0-beta.1;
new Windows/Linux artifacts require their own target-platform acceptance.
