# Infra Sentinel 2.0.2

This patch fixes Antigravity usage appearing on the wrong day or as a large
midnight spike after a conversation database is modified.

## Changes

- Recover missing generation timestamps through execution IDs and step creation
  metadata. The collector does not read conversation text or step payloads.
- Stop using database modification time as the usage date. Records without a
  reliable timestamp are excluded from all usage totals, with a separate
  diagnostic count.
- Preserve model attribution for recovered records and recalculate their daily
  and hourly usage from local metadata on the next collection.
- Build the app directly for ZIP distribution, without the unrelated DMG step.

No manual data reset is required. Local reference prices remain estimates,
not provider invoices.

## Download

Requires macOS 13 or newer on Apple Silicon (`arm64`). The app is ad-hoc
signed and is not Apple-notarized.
