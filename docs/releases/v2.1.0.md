# Infra Sentinel 2.1.0

本次更新集中改进 AI 用量观察：新增 DSH 采集和多客户端速度统计，明确模型后缀含义，并收紧 Agent 活动页。

## 更新内容

- Agent 活动默认每个来源一行摘要，展开后以双列呈现指标；说明可通过悬停或键盘聚焦查看，支持滚动和 Esc 关闭。
- Codex、OpenCode、DSH、Antigravity 的速度按轮次平均、请求平均、客户端流速分别标注，缺少可靠计时的记录不显示速度。
- 模型名旁显示参考计价依据；`-trial`/`-trail` 标为试用，`-free` 标为免费版，与疑似灰度分开。名称不代表实际扣费为零。
- 内置 api-price `2026.10.16.1`，Antigravity 历史参考价值按使用日有效价格汇总。目录仍可独立更新。
- Mihomo 不可用时继续更新设施状态；改进打包后的价格目录下载可靠性。

无需手动重置用量账本。API 参考价值不等于供应商账单，原始模型名和 Token 计数保持各自口径。

## Changes

- Compact Agent activity summaries, two-column diagnostic groups, and keyboard-accessible explanation hints.
- Read-only DSH usage plus separately labeled turn averages, request averages, and client stream rates across supported AI clients.
- Explicit trial/free model-name labels, bounded base-price references, and separate suspected-rollout indicators.
- Bundled api-price 2026.10.16.1 and effective-dated Antigravity history valuation; catalogs continue to update independently.
- Facility observation continues during Mihomo outages; packaged price downloads retain CA roots and tolerate release-download latency.

No manual ledger reset is required. API reference values are estimates, not provider invoices.
