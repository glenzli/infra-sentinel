# Infra Sentinel 2.0.0

Infra Sentinel 2.0.0 replaces the original Traffic Sentinel app with a resource-oriented desktop observer and a separately packaged local Agent.

## Highlights

- Tauri desktop shell with a quiet health menu, native notifications, bilingual settings, and independently failing resource modules.
- Local network attribution, multiple VPS billing sources, optional Xray user statistics, macOS resource observation, provider status, and Infra Protocol facility discovery.
- Codex, OpenCode, Antigravity, and Infer Runtime usage with model composition, current-day hourly buckets, older daily rollups, and clearly labeled local API reference values.
- Codex accounting from privacy-bounded rollout JSONL request increments, with fork-aware replay suppression and durable cross-file deduplication markers.

## Upgrade notes

- The bundle identifier changed from `com.local.traffic-sentinel` to `com.glenzli.infra-sentinel`, so macOS installs Infra Sentinel as a separate app.
- On first launch, Infra Sentinel copies `~/Library/Application Support/Traffic Sentinel/config.toml` only when the new configuration does not exist. It does not overwrite either configuration or delete the legacy directory.
- Traffic Sentinel v1 sample history is not imported into the v2 metric store. Codex history can only be rebuilt from rollout JSONL still present on this machine.

## Download

The release asset targets macOS 13 or newer on Apple Silicon (`arm64`). It is ad-hoc signed and is not Apple-notarized, so macOS may require manual first-launch confirmation.

- `Infra-Sentinel-2.0.0-macos13-arm64-unsigned.zip`
- `Infra-Sentinel-2.0.0-macos13-arm64-unsigned.zip.sha256`

The checksum file is generated from the exact archive uploaded to both GitHub and GitLab.

## Privacy and accounting

Infra Sentinel does not capture packets or retain prompts, responses, project files, or credentials. Token charts show local observations, not account quota or provider billing. Provider-reported cost, local API reference value, logical traffic, and VPS billing remain separate scopes.
