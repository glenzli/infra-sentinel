# Infra Sentinel 2.0.1

Infra Sentinel 2.0.1 moves text-token reference prices into the independent
`glenzli/api-price` release catalog and adds exact prices for GPT-6 Astra and
Gemini 3.8 Flash.

## Changes

- Bundles a validated offline price catalog and keeps it as the final fallback.
- Checks the latest `api-price` GitHub Release daily and, when an exact model is
  unpriced, at most once every six hours.
- Verifies catalog schema, bounded sizes, effective-date ranges, version, and
  SHA-256 before atomically installing a new local copy. HTTPS uses a bundled
  CA certificate store in the packaged Agent.
- Adds a manual price-catalog check under Settings → API pricing.
- Applies effective-dated prices to historical daily reference values, including
  Gemini 3.8 Flash's provider-published January 1, 2027 price change.

Update requests download the same two public release assets for every user.
They contain no observed model identifiers, token counts, prompts, or account
data. API reference values remain estimates rather than provider invoices.

## Download

The release asset targets macOS 13 or newer on Apple Silicon (`arm64`). It is
ad-hoc signed and is not Apple-notarized.

- `Infra-Sentinel-2.0.1-macos13-arm64-unsigned.zip`
- `Infra-Sentinel-2.0.1-macos13-arm64-unsigned.zip.sha256`
